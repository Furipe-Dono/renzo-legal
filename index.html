Política de privacidad de Renzo Assistant

Última actualización: 8 de noviembre de 2026

Esta política explica cómo Desarmaduría Dos Santos trata los datos personales de quienes se comunican mediante Renzo Assistant, un sistema de atención de consultas sobre repuestos automotrices a través de WhatsApp y, cuando se habilite, otros canales de mensajería.

1. Responsable y contacto

El servicio es ofrecido por Desarmaduría Dos Santos. Para consultas sobre privacidad, acceso, rectificación o eliminación de datos, escriba a renzfoot@hotmail.com.

2. Datos que pueden tratarse

Según la interacción, el sistema puede procesar el número telefónico, nombre o identificador del contacto, mensajes enviados, información sobre vehículos y repuestos consultados, historial necesario para dar continuidad a la atención y datos técnicos asociados al funcionamiento del servicio.

Se recomienda no enviar contraseñas, información bancaria ni otros datos sensibles por este canal.

3. Finalidades

La información se utiliza para responder consultas, verificar disponibilidad e información de repuestos, mantener el contexto de conversaciones, derivar solicitudes a una persona cuando corresponda, realizar seguimientos autorizados y mantener la seguridad y funcionamiento del servicio.

4. Servicios tecnológicos

Para operar, Renzo Assistant puede utilizar servicios de Meta/WhatsApp para mensajería, OpenAI para procesamiento automatizado de consultas y Airtable junto con almacenamiento técnico del sistema para gestionar información y continuidad de atención. El tratamiento por terceros está sujeto también a sus respectivas condiciones y políticas. No se publica el contenido de las conversaciones como parte de este sitio.

5. Conservación y seguridad

Los datos se conservarán durante el tiempo necesario para las finalidades descritas y las obligaciones legales aplicables. Los plazos concretos pueden variar según el tipo de información y las necesidades operativas. Se aplicarán medidas razonables para limitar el acceso a la información; ningún sistema puede garantizar seguridad absoluta.

6. Derechos y solicitudes

Puede solicitar información sobre sus datos personales, su corrección o eliminación escribiendo a renzfoot@hotmail.com. Cada solicitud será revisada y atendida según la normativa aplicable, considerando posibles obligaciones de conservación. Consulte también las instrucciones de eliminación de datos.

7. Cambios

Esta política puede actualizarse si cambian las funcionalidades del asistente, sus proveedores o las obligaciones legales. La versión vigente se publicará en esta misma página.
